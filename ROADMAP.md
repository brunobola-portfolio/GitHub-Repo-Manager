# Roadmap

## Current Focus (v3.x)

- [ ] GitLab import support
- [ ] Bitbucket import support
- [ ] Custom AI model selection (OpenAI, Claude, local models)
- [ ] Plugin system for community extensions
- [ ] Mobile app (React Native)
- [ ] SSO/SAML for enterprise customers
- [ ] Pricing page and billing settings UI

## Recently Shipped

- [x] Stripe billing integration (checkout, portal, webhooks, usage metering)
- [x] API key authentication with scoped permissions
- [x] Enhanced audit logging with searchable API
- [x] Per-tenant rate limiting (Redis-backed)
- [x] Subscription tiers (free/pro/enterprise) with feature gating
- [x] Security hardening (HSTS, CSP, CORS, credential encryption)
- [x] Sentry error tracking (frontend + backend)
- [x] Vercel + Railway deployment configuration
- [x] GitHub Actions CI/CD pipeline
- [x] Docker & Docker Compose support
- [x] Database abstraction layer (SQLite + PostgreSQL)
- [x] Redis session store for distributed deployments
- [x] BullMQ job queue for async operations
- [x] Multi-tenancy with user_id scoping
- [x] API versioning (/api/v1/)
- [x] Centralized Zod-validated configuration
- [x] Community health files (CONTRIBUTING, CODE_OF_CONDUCT, SECURITY)

## Foundation (v2.x)

- [x] AI-powered quality reports and suggestions
- [x] Semantic search with vector embeddings
- [x] Azure DevOps migration wizard (TFVC + Git)
- [x] Team collaboration with activity feeds
- [x] AI-generated README drafts
- [x] Bulk repository operations
- [x] GitHub Actions monitoring dashboard
- [x] Repository health scoring
- [x] Dark mode with system preference detection
