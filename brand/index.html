01 · Two optical cuts

Never one file scaled down

Below about 24 px the ring closes into a smudge and a 2.9 stroke lands between pixels. The small cut drops the ring, grows the node and thickens every stroke — same idea, redrawn. This is the difference between an icon and a logo shrunk.

02 · Colour

The house lime, spent in one place

RepoManager has no palette of its own. It inherits the official BolaLabs primary and spends it on exactly one element: the attending node. Everything else is ink.

Inherited rule

The lime is fill only — never text. For a coloured word use #8fd23f on dark (11:1) or #3f7d12 on light (~5:1).

Collision to avoid

The product's UI uses green for passing. The brand lime sits at H≈87° and must never mean "healthy", or the brand and the status language start contradicting each other.

06 · Never

What breaks it

Never

Recolour the node. It is the only carrier of brand recognition.

Never

Add a gradient, glow or shadow. The previous logo had four gradients and three blurs, and that is why it died at 16 px and lost detail converting to .ico.

Never

Scale the display cut below 25 px, or use the mark below 16 px.

Never

Use the BolaLabs flask as the product icon. The flask is the company; the rail is the product.

Never

Borrow anything from GitHub — Octocat, wordmark or palette. RepoManager manages GitHub and is not affiliated with it.
