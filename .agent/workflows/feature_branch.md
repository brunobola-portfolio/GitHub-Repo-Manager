---
description: Create a new feature branch from main
---

1. Ask the user for the feature name (e.g., "add-repo-search").

2. Switch to the main branch.
// turbo
3. Run `git checkout main`

4. Pull the latest changes.
// turbo
5. Run `git pull origin main`

6. Create and switch to the new feature branch.
// turbo
7. Run `git checkout -b feature/[feature-name]`

8. Confirm the branch was created and is ready for development.
