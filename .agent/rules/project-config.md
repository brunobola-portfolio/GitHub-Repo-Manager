# GitHub Repo Manager - Project Configuration

## Project Overview
This is a React + Express full-stack application for managing GitHub repositories.

## Technology Stack
- Frontend: React 18 with Vite (port 5173)
- Backend: Express.js API (port 3001)
- Authentication: GitHub OAuth
- Package Manager: npm

## Development Commands
- `cmd /c npm run dev:all` - Start both frontend and backend simultaneously
- `cmd /c npm run dev` - Start frontend only (port 5173)
- `cmd /c npm run dev:server` - Start backend only (port 3001)
- `cmd /c npm run build` - Build for production
- `cmd /c npm start` - Run production server

**IMPORTANT**: Always use `cmd /c` prefix when running npm commands in PowerShell to avoid issues.

## Git Conventions
- Default branch: `main` (not `master`)
- Always target `main` for merges and PRs
- Never auto-commit or push without explicit user permission

## Response Style Preferences
- Be concise and professional
- Focus on essential information to save tokens
- Skip flattery and unnecessary acknowledgments
- Only provide detailed explanations when explicitly requested
